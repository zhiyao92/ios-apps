How I build

Swift & SwiftUI

Every shipped app, no exceptions — MVVM throughout, one ViewModel per screen.

Firebase

Firestore, Auth, Analytics, Crashlytics and App Check, shared across a multi-app portfolio on the same project where it makes sense.

RevenueCat

Subscription entitlements and paywalls across every app that monetises.

Protocol-first architecture

Services sit behind a protocol so every layer can be faked in a test — a service that can't be faked is a defect, not a feature.

Tested by default

New logic ships with unit tests in the same change, not after. Several apps carry 100+ tests gating CI.

Instrumentation discipline

GA4 plus a purpose-built internal dashboard that maps screen and event coverage across the whole portfolio — a feature that isn't measured is a feature that can't be improved.
